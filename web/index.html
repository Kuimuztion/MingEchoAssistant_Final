游戏账户

连接库街区账号，同步角色、声骸与面板数据

库街区连接
国服默认固定，如需其他区服请手动编辑 kuro_config.json
获取库街区 Token 步骤
  1. 用浏览器打开 库街区鸣潮 Wiki：https://wiki.kurobbs.com/mc/home
  2. 点击右上角登录你的库街区账号（手机号+验证码或密码）
  3. 登录后按 F12 打开开发者工具，切换到 网络（Network） 标签，筛选 Fetch/XHR
  4. 按 F5 刷新页面，在请求列表中任选一个（如 getPage），在请求标头中找到 Token 字段，复制其值
  5. 游戏角色 ID 和区服 ID 可在库街区「我的」页面的角色卡中查看，或从抓包请求的 form 数据中获取

注意：Token 会定期过期，失效后重新抓包获取即可。本软件仅在本地保存 Token，不会上传到任何第三方服务器。

获取短信验证码步骤
  1. 打开手机上的库街区 App（或网页版 kurobbs.com）
  2. 进入登录页面，输入你的手机号，点击「获取验证码」
  3. 完成官方的人机验证，等待收到短信
  4. 将收到的 6 位数字验证码 输入到本软件的短信登录弹窗中
  5. 点击「登录」即可自动获取 Token 并发现角色 ID

说明：由于库街区短信接口限制，本软件内的「获取验证码」按钮可能无法直接下发短信，请通过官方 App 获取验证码后输入。验证码有效期通常为 5 分钟。

关于此项目

鸣潮助手 · Ming Echo Assistant — 项目说明与致谢

项目简介

鸣潮助手是一款由玩家自发开发的非官方粉丝工具，旨在为 PC 端玩家提供便捷的角色面板查看和声骸评分功能。 由于库街区 PC 端暂不支持查看角色面板数据，本工具通过库街区公开 API 获取玩家自己的角色数据，并在本地进行展示与分析。

本工具不修改游戏文件、不注入游戏进程、不作弊、不影响其他玩家，仅作为数据查看与评分辅助工具使用。

致谢

库街区 / 库洛游戏 — 感谢库街区提供的角色图鉴与公开 API，本工具的角色数据、声骸数据、武器数据均来源于库街区。

Agnes AI — 感谢 Agnes AI 提供的免费多模态大模型 API（agnes-2.5-flash），为本工具的智能评分、养成推荐和对话助手提供算力支持。

开源社区 — 感谢 waves-plugin 等开源项目对库街区 API 的逆向与文档化工作，为本工具的开发提供了重要参考。

数据与隐私

所有数据仅保存在本地，不上传任何服务器。

• 你的库街区 Token、角色数据、声骸数据均保存在你自己的电脑本地（项目目录下的 kuro_config.json）

• 本工具不收集、不上传、不分析任何用户个人信息

• Agnes AI API 调用仅传输你主动输入的评分数据和对话内容，不包含你的库街区账号凭证

• 你可以随时删除 kuro_config.json 来清除所有本地数据

请求频率限制

为避免对库街区服务器造成压力，本工具内置了请求间隔限制：

• 对库街区 API 的连续请求之间至少间隔 1 秒

• 单分钟内请求总数不超过 30 次

• 角色详情数据会在本地缓存，重复查看同一角色不会重复请求服务器

请合理使用本工具，不要进行高频批量抓取，以免对库街区服务器造成负担。
